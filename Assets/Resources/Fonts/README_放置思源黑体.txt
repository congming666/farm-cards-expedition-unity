把可商用的思源黑体字体资产放到本目录，资源名必须为 SourceHanSans
（即 Assets/Resources/Fonts/SourceHanSans.ttf 导入后的 Font，运行时由 FontLoader 通过
Resources.Load<Font>("Fonts/SourceHanSans") 加载）。

授权：思源黑体 / Source Han Sans / Noto Sans CJK 使用 SIL Open Font License，可随商业软件分发。
切勿把微软雅黑(Microsoft YaHei)、苹方(PingFang SC) 等系统字体随包分发——其版权不属于开发者。
在取得正式字体资产前，游戏会回退到系统动态字体，仅供开发期运行。
